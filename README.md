## 3. Project Overview

Sweet Crumbs Bakery is a small bakery business website created to introduce customers to the bakery and the products and services it offers. The business focuses on freshly baked products that can be enjoyed for everyday treats as well as special occasions.

The website gives visitors an opportunity to learn more about Sweet Crumbs Bakery, view examples of the products, explore the services available and find contact information for enquiries and orders. The website is designed to give the business a clear online presence while making it simple for customers to move between the different pages.

The project is developed as a multi-page website using HTML to organise the structure and content of each page (Mozilla Developer Network, 2025a). CSS is used to control the presentation, layout, typography, spacing and colours, while JavaScript is included in the project for interactive functionality as the website develops (Mozilla Developer Network, 2025b; Mozilla Developer Network, 2025c). Visual Studio Code is used as the development environment (Microsoft, n.d.).

## 4. Website Goals and Objectives

The main goals of the Sweet Crumbs Bakery website are:

1. To introduce visitors to Sweet Crumbs Bakery and explain what the business provides.
2. To present the bakery's products and services in a clear and organised way.
3. To allow customers to view bakery products through the gallery.
4. To provide useful information for customers who want to make enquiries or place orders.
5. To create simple navigation so visitors can move between all sections of the website easily.
6. To create a consistent visual identity for Sweet Crumbs Bakery using a suitable bakery-inspired colour scheme.
7. To make the website responsive so that it can be viewed on desktop, tablet and mobile screens.
8. To provide a foundation that can be improved with additional functionality in future project stages.

## 5. Key Features and Functionality

### Home Page
The Home page introduces Sweet Crumbs Bakery and gives visitors an overview of the type of baking and occasions the business caters for. It also provides links to the main areas of the website.

### About Us Page
The About Us page provides background information about Sweet Crumbs Bakery and explains the values that are important to the business, such as quality baking, customer satisfaction and creating products for different occasions.

### Services Page
The Services page presents the bakery's products and ordering services. It also includes an example price guide to give customers an idea of the products available.

### Gallery Page
The Gallery page displays examples of Sweet Crumbs Bakery products. The images help visitors understand the type of baked goods and presentation associated with the business.

### Contact Us Page
The Contact Us page gives customers a way to make enquiries about Sweet Crumbs Bakery. It includes a contact form that can be used as the starting point for future customer communication functionality.

### Navigation
The website uses links between the HTML pages so that visitors can move around the website without difficulty. The main navigation includes:
* Home
* About Us
* Services
* Gallery
* Contact Us

### Website Technologies
The project uses:
* **HTML5** -- used to structure the pages and organise the website content.
* **CSS** -- used for the visual design, layout, typography, spacing, colours and responsive styling.
* **JavaScript** -- included for interactive functionality as the website develops.
* **Visual Studio Code** -- used as the development environment.
* **SVG image files** -- used to provide visual content for the bakery website.

## 7. Part 1 Details & Part 2 Development

Part 1 established the main structure and content of the Sweet Crumbs Bakery website. The project was developed around the bakery business idea, with the main pages created to introduce the business, explain its services, display products and provide a way for customers to make enquiries.

For Part 2, the focus was placed on improving the presentation and usability of the website through the external CSS stylesheet. The styling was reorganised so that the pages have a consistent structure while still having a visual identity that suits Sweet Crumbs Bakery.

The Part 2 development includes:
* Improving the external CSS stylesheet used by the website pages.
* Creating a consistent bakery-focused colour palette that is different from the reference business website.
* Improving typography, spacing, borders, buttons and page sections.
* Using Flexbox and CSS Grid where suitable for page layouts, cards and the gallery.
* Adding hover, focus and active navigation states to improve interaction.
* Improving the responsive layout for desktop, tablet and mobile screen sizes.
* Keeping the Sweet Crumbs Bakery business idea, pages and content as the basis of the website.
* Updating the README documentation to record the development work completed for Part 2.
